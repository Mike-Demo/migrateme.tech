# Carbon disclosure for universal.migrateme.tech

Domain: universal.migrateme.tech

MigrateMe Universal publishes this file as a good-faith disclosure. Hosting
sustainability for this domain is unverified: we make no green-hosting claim
and no carbon-neutral claim. No measurement of actual energy use or emissions
has been made.

What is true by design: conversions run locally in the visitor's browser, so
migrating content here does not upload files to, or run jobs on, a server.
The page footer shows a per-visit CO2 estimate computed in the browser from
the page's transfer size using the CO2.js model; it is an estimate, not a
measurement.
