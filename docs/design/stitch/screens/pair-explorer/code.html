The Subdomain is the Fidelity Contract

Every directed migration path in MigrateMe is registered as an explicit RFC contract hosted on its own subdomain: https://{source}.to.{destination}.migrateme.tech.

Before running any script, you or your AI agent can query the live topology manifest. The manifest yields AST schemas, field mapping tables, and an exhaustive list of preserved versus unmapped properties.

Execution Rule Manifest

In-Browser WebAssembly worker processes incoming XML/JSON stream. Post entities are converted to unified AST nodes, AST transformers normalize inline HTML into JSX MDX blocks, and frontmatter YAML is synthesized with RFC 3339 timestamps.

Field-Level AST Mapping Matrix
wp:post_title→ title (Frontmatter)
wp:post_date_gmt→ date (ISO 8601)
wp:post_name→ slug / filename
content:encoded→ unified Markdown AST
wp:postmeta (_yoast_*)→ meta.seo.* (YAML)
Deterministic Loss Guarantee

Zero telemetry is transmitted off this machine. Transformations occur inside your local browser memory space or CLI sandbox.
